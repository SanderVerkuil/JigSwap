# Snel zoeken (opdrachtenpalet)

JigSwap heeft een globale zoekfunctie waarmee je snel alles vindt.

- **Openen:** druk op **Cmd/Ctrl + K**, of klik op het zoekvak (**Zoek puzzels, mensen, kringen…**) in de bovenbalk op desktop.
- **Met niets ingetypt:** je ziet navigatiebestemmingen om naartoe te springen en snelle-actie-snelkoppelingen. **Mijn gegevens exporteren** is er een van: daarmee download je meteen je gegevens.
- **Typ 2 of meer tekens:** live resultaten verschijnen, gegroepeerd in **In je bibliotheek** (je eigen exemplaren, die openen op je pagina Mijn puzzels), **Puzzels** (de catalogus), **Mensen**, **Kringen** en **Collecties**. **In je bibliotheek** zoekt in de 500 exemplaren die je het laatst hebt toegevoegd; wil je in al je puzzels zoeken, gebruik dan het zoekvak op **Mijn puzzels**.
- **Selecteer een resultaat** om er direct naartoe te navigeren.
