# Je bibliotheek

Beheer de exemplaren die je bezit, organiseer ze in collecties, leg elke voltooiing vast en zie je persoonlijke inzichten groeien.

Wil je één bibliotheek delen met de mensen met wie je samenwoont, zie dan
[Huishoudens](/docs/sharing-and-exchanges/households).
